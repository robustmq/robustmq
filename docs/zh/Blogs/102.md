# mq9 MCP Server 使用手册

mq9 MCP Server 内置在 RobustMQ Admin Server 中，通过 `POST /mcp` 端点提供 JSON-RPC 2.0 接口。任何支持 MCP 协议的 AI 工具（Claude Desktop、Cursor、Cline 等）都可以直接接入，无需理解底层 NATS 协议。

## 接入配置

Admin Server 默认监听 **8080** 端口，随 RobustMQ Broker 同进程启动。MCP Server 启动时自动连接本机 NATS（默认 4222 端口）。

**端点地址**

```
POST http://{host}:8080/mcp
Content-Type: application/json
```

**Claude Desktop 配置**

编辑 `~/Library/Application Support/Claude/claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "mq9": {
      "url": "http://localhost:8080/mcp"
    }
  }
}
```

重启 Claude Desktop 后，工具列表中出现 `mq9_*` 系列工具即表示接入成功。

**验证连接**

```bash
curl -s -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"ping","params":{}}'
# 返回 {"jsonrpc":"2.0","id":1,"result":{}} 表示正常
```

## 工具一览

| 工具名 | 用途 |
|--------|------|
| `mq9_create_mailbox` | 创建 mailbox |
| `mq9_send_message` | 发送消息 |
| `mq9_fetch_messages` | 拉取并消费消息 |
| `mq9_ack_message` | 确认消息已处理 |
| `mq9_query_mailbox` | 查看消息（不推进消费位点） |
| `mq9_register_agent` | 注册 Agent |
| `mq9_discover_agents` | 发现 Agent |
| `mq9_unregister_agent` | 注销 Agent |

## mq9_create_mailbox

收发消息前需要先创建 mailbox。mailbox 名字必须小写，可包含字母、数字和点。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 否 | mailbox 名字，省略时由 broker 自动生成 |
| `ttl` | integer | 否 | 存活时长（秒），省略时使用 broker 默认值 |
| `desc` | string | 否 | 可读描述 |

```bash
curl -s -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0","id":1,"method":"tools/call",
    "params":{
      "name":"mq9_create_mailbox",
      "arguments":{
        "name":"agent.order.inbox",
        "desc":"订单处理 Agent 的收件箱"
      }
    }
  }'
```

```json
{"result":{"mail_address":"agent.order.inbox","created":true}}
```

## mq9_send_message

向指定 mailbox 发送一条消息。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `mail_address` | string | 是 | 目标 mailbox 地址 |
| `payload` | string | 是 | 消息内容（UTF-8，可以是纯文本或 JSON） |
| `priority` | string | 否 | `normal`（默认）、`urgent`、`critical` |

```bash
curl -s -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0","id":2,"method":"tools/call",
    "params":{
      "name":"mq9_send_message",
      "arguments":{
        "mail_address":"agent.order.inbox",
        "payload":"{\"order_id\":\"ORD-001\",\"action\":\"process\"}",
        "priority":"urgent"
      }
    }
  }'
```

```json
{"result":{"msg_id":42,"mail_address":"agent.order.inbox"}}
```

返回的 `msg_id` 是消息唯一标识，后续 ack 时使用。

## mq9_fetch_messages

从 mailbox 拉取消息并推进消费位点。处理完成后需调用 `mq9_ack_message` 确认。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `mail_address` | string | 是 | 目标 mailbox 地址 |
| `group_name` | string | 是 | 消费组名称，建议用 Agent ID。同组共享消费位点，不同组互不影响 |
| `reset_to` | string | 否 | 重置消费起始位置（见下表），省略则从上次 ack 位置继续 |
| `max_messages` | integer | 否 | 最多返回多少条，默认 100 |

`reset_to` 取值：

| 值 | 含义 |
|----|------|
| 省略 | 从上次 ack 的位置续拉 |
| `"earliest"` | 重置到最早一条 |
| `"latest"` | 跳过历史，只收新消息 |
| Unix 时间戳（如 `1746000000`） | 从该时间之后开始 |
| msg_id 整数（如 `42`） | 从该消息开始（含） |

```bash
# 正常续拉
curl -s -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0","id":3,"method":"tools/call",
    "params":{
      "name":"mq9_fetch_messages",
      "arguments":{
        "mail_address":"agent.order.inbox",
        "group_name":"order-agent-001"
      }
    }
  }'
```

```json
{
  "result":{
    "messages":[
      {"msg_id":42,"payload":"{\"order_id\":\"ORD-001\"}","priority":"urgent","create_time":1746001234}
    ]
  }
}
```

## mq9_ack_message

确认消息已处理。下次 fetch 将从 `msg_id + 1` 开始。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `mail_address` | string | 是 | mailbox 地址 |
| `group_name` | string | 是 | 消费组名称（与 fetch 时保持一致） |
| `msg_id` | integer | 是 | 最后一条成功处理的消息 ID |

```bash
curl -s -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0","id":4,"method":"tools/call",
    "params":{
      "name":"mq9_ack_message",
      "arguments":{
        "mail_address":"agent.order.inbox",
        "group_name":"order-agent-001",
        "msg_id":42
      }
    }
  }'
```

```json
{"result":{"msg_id":42,"acked":true}}
```

## mq9_query_mailbox

查看 mailbox 中的消息，**不影响消费位点**。适合检查消息内容而不消费。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `mail_address` | string | 是 | mailbox 地址 |
| `key` | string | 否 | 按消息 key 精确过滤 |
| `tags` | string[] | 否 | 按 tag 过滤，消息须同时带有所有指定 tag |
| `since` | integer | 否 | 只返回此 Unix 时间戳（秒）之后的消息 |
| `limit` | integer | 否 | 最多返回多少条，默认 20 |

```bash
curl -s -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0","id":5,"method":"tools/call",
    "params":{
      "name":"mq9_query_mailbox",
      "arguments":{
        "mail_address":"agent.order.inbox",
        "tags":["billing","urgent"],
        "limit":5
      }
    }
  }'
```

```json
{"result":{"messages":[{"msg_id":38,"payload":"...","priority":"urgent","create_time":1746001100}]}}
```

## mq9_register_agent

将 Agent 注册到 mq9 注册中心。建议 Agent 启动时调用一次。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | Agent 唯一名称 |
| `payload` | string | 是 | 能力描述（纯文本或 A2A AgentCard JSON） |

```bash
curl -s -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0","id":6,"method":"tools/call",
    "params":{
      "name":"mq9_register_agent",
      "arguments":{
        "name":"order-agent-001",
        "payload":"{\"capabilities\":[\"order_processing\"],\"inbox\":\"agent.order.inbox\"}"
      }
    }
  }'
```

```json
{"result":{"name":"order-agent-001","registered":true}}
```

---

## mq9_discover_agents

在注册中心查找具有特定能力的 Agent。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | 否 | 能力查询词（自然语言或 `tag:xxx` 格式） |
| `limit` | integer | 否 | 最多返回多少条，默认 20 |

```bash
curl -s -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0","id":7,"method":"tools/call",
    "params":{
      "name":"mq9_discover_agents",
      "arguments":{
        "query":"order_processing"
      }
    }
  }'
```

```json
{"result":{"agents":[{"name":"order-agent-001","payload":"..."}]}}
```

---

## mq9_unregister_agent

从注册中心移除 Agent。建议 Agent 正常退出时调用。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 要注销的 Agent 名称 |

```bash
curl -s -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0","id":8,"method":"tools/call",
    "params":{
      "name":"mq9_unregister_agent",
      "arguments":{"name":"order-agent-001"}
    }
  }'
```

```json
{"result":{"name":"order-agent-001","unregistered":true}}
```

## 完整使用流程示例

两个 Agent 之间互发消息的最小流程：

```bash
# 1. Agent A 创建自己的 mailbox
# POST mq9_create_mailbox { name: "agent.a.inbox" }

# 2. Agent B 创建自己的 mailbox
# POST mq9_create_mailbox { name: "agent.b.inbox" }

# 3. Agent A 向 Agent B 发送消息
# POST mq9_send_message { mail_address: "agent.b.inbox", payload: "hello from A" }
# 返回 msg_id: 1

# 4. Agent B 拉取消息
# POST mq9_fetch_messages { mail_address: "agent.b.inbox", group_name: "agent-b" }
# 返回 messages: [{ msg_id: 1, payload: "hello from A" }]

# 5. Agent B 确认消费
# POST mq9_ack_message { mail_address: "agent.b.inbox", group_name: "agent-b", msg_id: 1 }

# 6. Agent B 再次 fetch → messages 为空，说明没有新消息
```

## 错误处理

出错时返回标准 JSON-RPC 错误结构：

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32603,
    "message": "mailbox agent.order.inbox does not exist"
  }
}
```

常见错误：

| 错误信息 | 原因 | 处理方式 |
|----------|------|----------|
| `mailbox xxx does not exist` | mailbox 未创建 | 先调用 `mq9_create_mailbox` |
| `mq9 tools require nats-broker to be running` | NATS broker 未启动 | 检查 Broker 进程 |
| `missing 'name' in tools/call params` | 请求格式错误 | 检查 JSON-RPC 格式 |
